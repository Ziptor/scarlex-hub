Быстрый старт

Scarlex — это управляемый шлюз, который понимает и /v1/messages от Anthropic, и /v1/chat/completions от OpenAI. Укажи любой SDK на базу ниже, передай ключ как Authorization: Bearer или x-api-key — этого достаточно.

Базовый URL

URL
https://api.scarlex.ru/v1

Твой API-ключ

KEY
sk-scarlex-XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX

Получи ключ в личном кабинете — 1M токенов в подарок при регистрации.

Hello, world

Скопируй в терминал, чтобы проверить round-trip. В примере используется модель Claude.

cURL
curl https://api.scarlex.ru/v1/messages \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "content-type: application/json" \
  -d '{
    "model": "claude-haiku-3.5",
    "max_tokens": 64,
    "messages": [{"role":"user","content":"Say hi in one word."}]
  }'
cURL
curl https://api.scarlex.ru/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "content-type: application/json" \
  -d '{
    "model": "claude-haiku-3.5",
    "messages": [{"role":"user","content":"Say hi in one word."}]
  }'

Соответствующий SDK-гайд в сайдбаре слева показывает зеркальный запрос для выбранного формата.

cURL

Прямой запрос к API. Совместим с форматом OpenAI Chat Completions и Anthropic Messages.

OpenAI-формат

cURL · /v1/chat/completions
curl https://api.scarlex.ru/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "claude-opus-4.7",
    "messages": [
      {"role": "user", "content": "Привет!"}
    ]
  }'

Anthropic-формат

cURL · /v1/messages
curl https://api.scarlex.ru/v1/messages \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "claude-opus-4.7",
    "max_tokens": 1024,
    "messages": [
      {"role": "user", "content": "Привет!"}
    ]
  }'

OpenAI Responses API

Stateless: previous_response_id не поддерживается, передавайте всю историю в input.

cURL · /v1/responses
curl https://api.scarlex.ru/v1/responses \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "claude-opus-4.7",
    "instructions": "Ты лаконичный ассистент.",
    "input": "Объясни замыкания одним предложением."
  }'

Полный гайд по Responses API — в личном кабинете.

Streaming

Добавьте "stream": true — ответ придёт в формате Server-Sent Events.

cURL · SSE
curl https://api.scarlex.ru/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-sonnet-4","stream":true,"messages":[{"role":"user","content":"Hi"}]}'

Claude Code CLI

Подключите Scarlex как провайдер Claude Code через файл настроек — переписывать ничего не нужно.

Путь к файлу

Windows: %USERPROFILE%\.claude\settings.json
macOS / Linux: ~/.claude/settings.json

JSON · settings.json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.scarlex.ru",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "ANTHROPIC_MODEL": "claude-opus-4.7",
    "ANTHROPIC_SMALL_FAST_MODEL": "claude-haiku-3.5",
    "DISABLE_NON_ESSENTIAL_MODEL_CALLS": "1",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  }
}

После сохранения перезапустите Claude Code — все запросы пойдут через Scarlex. Биллинг идёт по лимиту вашего API-ключа.

OpenCode

      "name": "Scarlex",

        "apiKey": "YOUR_API_KEY"

      "models": {

          "name": "Claude Opus 4.7",
          "limit": { "context": 200000, "output": 64000 },
          "variants": { "high": {}, "medium": {}, "low": {} }

oh-my-opencode

Плагин для OpenCode с мульти-агентной системой. Каждый агент получает свою модель — Sisyphus разруливает делегирование.

1 · Подключите плагин

Добавьте в opencode.json:

JSON
"plugin": ["oh-my-opencode@latest"]

2 · Назначьте модели агентам

Создайте oh-my-opencode.json:

JSON · oh-my-opencode.json
{
  "agents": {
    "sisyphus":   { "model": "SCARLEX/claude-opus-4.7" },
    "oracle":     { "model": "SCARLEX/claude-opus-4.7" },
    "librarian":  { "model": "SCARLEX/claude-sonnet-4" },
    "explore":    { "model": "SCARLEX/claude-sonnet-4" },
    "prometheus": { "model": "SCARLEX/claude-opus-4.6" },
    "metis":      { "model": "SCARLEX/claude-haiku-3.5" },
    "momus":      { "model": "SCARLEX/claude-sonnet-4-thinking" }
  },
  "categories": {
    "ultrabrain": { "model": "SCARLEX/claude-opus-4.7" },
    "quick":      { "model": "SCARLEX/claude-haiku-3.5" },
    "deep":       { "model": "SCARLEX/claude-opus-4.6" }
  }
}

Python и Node SDK

Scarlex полностью совместим с официальным openai SDK — достаточно сменить base_url.

Python

Python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.scarlex.ru/v1",
)

resp = client.chat.completions.create(
    model="claude-opus-4.7",
    messages=[{"role": "user", "content": "Привет!"}],
)
print(resp.choices[0].message.content)

Node.js

TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "YOUR_API_KEY",
  baseURL: "https://api.scarlex.ru/v1",
});

const resp = await client.chat.completions.create({
  model: "claude-opus-4.7",
  messages: [{ role: "user", content: "Привет!" }],
});

console.log(resp.choices[0].message.content);
