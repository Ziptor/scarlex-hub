Подробнее о бонусах

Частые вопросы.
Когда начисляется 50 ₽?
Бонус приходит автоматически в момент когда друг подтверждает email при регистрации. Получаете оба: +50 ₽ тебе и +50 ₽ другу. Деньги падают на основной баланс сразу.
Что такое 5% lifetime?
С каждого пополнения друга 5% автоматически идёт тебе на баланс. Без срока действия — даже если друг будет пополнять через год, ты будешь получать свой процент.
Можно ли тратить реф-бонусы?
Да. Все бонусы (и 50 ₽, и 5%) идут на твой основной баланс. Используй их для оплаты любых моделей через API так же как обычные деньги.
Кого считают «активным» рефералом?
Друга, который сделал хотя бы одно пополнение баланса (на любую сумму). Просто зарегистрированные — считаются в графе «Приглашено», но не в «Активных».
Есть ли лимит на количество приглашённых?
Нет. Приглашай сколько хочешь — бонусы начисляются за каждого. Главное чтобы это были реальные люди (один человек ≠ много аккаунтов с одного устройства).
Где увидеть кто пригласил меня?
В профиле. Если кто-то пригласил тебя — там покажется его username.
